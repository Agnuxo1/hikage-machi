Sources:Takamatsu City / MLIT Project PLATEAU, Takamatsu2022CityGMLv4; Kotoden Bus GTFS(snapshot10Nov2026). Processed by Francisco Angulo de Lafuente. Attribution4.0International applies to these data derivatives; the repository MIT licence concerns original code. See ../RIGHTS_AND_PROVENANCE.md.

BUILDINGS.csv.gz contains268,154objects with identifiers, source mesh, presence ofLOD1/LOD2elements and min/max native coordinates. EPSG6697 axes are latitude(degrees),longitude(degrees),gravity-related height(metres). These are coordinate extents, not exact footprints, topology, shading, irradiance or ground-truth current buildings. GTFS_STOPS.csv contains658stop records and their timetable-source coordinates, not observations of actual service. MANIFEST.json gives file and uncompressed-source hashes.
