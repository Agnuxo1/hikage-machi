Sources: Takamatsu City / MLIT Project PLATEAU, Takamatsu 2022 CityGML v4; Kotoden Bus GTFS (snapshot 10 Nov 2026). Processed by Francisco Angulo de Lafuente. Attribution 4.0 International applies to these data derivatives; the repository MIT licence concerns original code. See ../RIGHTS_AND_PROVENANCE.md.

BUILDINGS.csv.gz contains 268,154 objects with identifiers, source mesh, presence of LOD1/LOD2 elements and min/max native coordinates. EPSG:6697 axes are latitude (degrees), longitude (degrees), gravity-related height (metres). These are coordinate extents, not exact footprints, topology, shading, irradiance or ground-truth current buildings. GTFS_STOPS.csv contains 658 stop records and their timetable-source coordinates, not observations of actual service. MANIFEST.json gives file and uncompressed-source hashes.
